## External credentials in the Skill Set Go handbook

The handbook recommends completing four approved external credentials by the final week and suggests starting Week 1 with:

- Forage Software Engineering simulation
- IBM SkillsBuild blockchain/software-related credential

Other listed options include Infosys Springboard, Simplilearn SkillUp, and AWS Educate. Course/credential availability can change, so verify the credential is actually issued before relying on it.
